# Imuniza+ Frontend

Base oficial inicial do frontend da plataforma de gestão de imunização.

## Estado atual

- React + TypeScript + Vite
- Tailwind CSS
- Rotas municipais e Super Admin
- Autenticação demonstrativa local
- Dados mockados, sem backend real

## Executar

```bash
npm install
npm run dev
```

## Validar produção

```bash
npm run typecheck
npm run build
```
